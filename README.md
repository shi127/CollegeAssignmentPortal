# College Assignment Submission Portal

A database-driven web application developed using Java Servlets, JSP, JDBC, MySQL and Multithreading.

## Technologies Used

- Java
- JSP
- Servlets
- JDBC
- MySQL
- Apache Tomcat
- Apache NetBeans
- HTML
- CSS
- Multithreading using Timer and TimerTask

## Main Features

### Student
- Student login
- View available assignments
- View assignment details and deadlines
- Submit assignments
- View submitted assignments
- Logout

### Faculty
- Faculty login
- Faculty dashboard
- Create assignments
- View and manage own assignments
- Edit assignments
- Delete assignments
- View student submissions
- View student login activity

## Database

Database Name:

`college_assignment_portal`

The database script is provided in:

`schema.sql`
